# 🏁 Turbo Race

Turbo Race is an exciting racing game where players can choose between
bikes and cars, race on different maps, increase their level, improve
their rank, collect rewards, and set new records.

## 🎮 Features

- 🏍️ Multiple Bikes
- 🚗 Multiple Cars
- 🗺️ Different Maps & Tracks
- ⭐ Player Levels
- 🏆 Rank System
- 🎁 Daily Rewards
- 💰 Coins & Diamonds
- ⚡ 1X, 1.5X & 2X Race Speed
- 🏁 High Score / Record System

## 🏍️ Vehicles

### Bikes
- Ninja 900 ZX
- Hayabusa 1300R
- Harley Thunder

### Cars
- Lamborghini GT
- Ferrari X
- Supra MK5
- GTR R35
